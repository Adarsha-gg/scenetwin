# TRIBE validation/statistics ideas for SceneTwin

Scope: validation/ablation/null/reviewer-defense ideas only. I did not edit project source files or run new experiments. Ideas are grounded in existing local artifacts, especially the TRIBE calibration nulls, binary triage positives, router validation, and corrected-ladder/tie-handling failures.

## Local evidence inspected

- `wiki/research/scenetwin-tribe-role-analysis.md` — TRIBE per-clip features do **not** calibrate continuous ensemble noise; 12 feature correlations max `|r|=0.342`, all `p>0.16`; gating thresholds all reduce rho; in-bench binary `all4_fail` triage is `AUC=1.00`, `recall@2/18=100%`; external counterfactual calibration vanishes (`accessibility_gap r=+0.025, p=0.849`; `description_gain r=-0.145, p=0.269`; `alignment_cosine r=-0.004, p=0.976`).
- `wiki/research/scenetwin-tribe-failure-forecast.md` — published in-bench risk queue: `mean_standard_slot_score` ranks the two `all4_fail` clips first; hypergeometric/exact `p=0.00653595`, Bonferroni caveat `p=0.065`; warning that result is post-hoc and only `n=2` positives.
- `cursor/findings/tribe-clip-level-triage.md` — corrected 60-clip OOD framing: TRIBE is clip-level triage, not a rho booster; ADQA-only failures `10/60`, gap fail `0.267` vs ok `0.158`, `AUC=0.79`, one-sided `p=0.0018`; ensemble failures only `2/60`, `AUC=1.00` but underpowered.
- `cursor/findings/dual-signal-complementarity.md` — strict inequality over discrete ADQA ties produced a retracted false dominance claim; tie-aware scoring is mandatory for reviewer defense.
- `wiki/research/scenetwin-negative-results.md` — eight paper metrics, six fusions, TRIBE calibration, and TRIBE-gated routing did not beat the two-signal ensemble; closure/Description Gain/MVRR/ROI typing/neural closure were dead branches.
- `cursor/research/output/tribe_counterfactual_summary.md` — explicit decision criterion closed the calibration-layer framing unless external calibration reaches `r < -0.5, p < 0.05`; it did not.
- `cursor/research/output/tribe_router_validation_summary.json` — gap-targeted/generative TRIBE validations show several positive matched-subset tests, plus a strong negative: `tribe_vs_pro_priority.csv` loses to VLM/pro/uniform priority (`wins=16`, `losses=39`, `sign_p_tribe_gt_vlm=0.99949`).
- CSV headers sampled from: `cursor/research/output/scenetwin_per_clip_tribe_calibration.csv`, `cursor/research/output/tribe_counterfactual_external_calibration.csv`, `cursor/research/output/tribe_counterfactual_external_t3_loss_auc.csv`, `cursor/research/output/tribe_counterfactual_feature_auc.csv`, `cursor/research/output/tribe_counterfactual_vs_existing.csv`, `output/scenetwin_timing_20clip/tribe_native/tribe_failure_forecast.csv`.

## Highest-priority reviewer-defense bundle

If only a small number can be run before submission, prioritize:

1. **Family-wise feature-selection null (#3)** — directly addresses post-hoc feature selection behind `AUC=1.00`.
2. **Bootstrap/top-k OOD triage curve (#7)** — strongest external-generalization defense for TRIBE as review triage.
3. **Tie-aware target audit (#15)** — prevents another strict-inequality artifact.
4. **Calibration equivalence test (#17)** — turns the external calibration failure into a statistically defensible null.
5. **Claims audit (#25)** — cheap and prevents overclaiming in the draft.

## Guardrails for interpretation

- Do **not** claim TRIBE boosts within-clip rho unless a candidate-level TRIBE feature is introduced and validated. Existing TRIBE gaps are clip-level constants.
- Do **not** headline `AUC=1.00` without saying `n=2 positives`, post-hoc feature selection, and Bonferroni caveat.
- Do **not** revive continuous calibration unless external validation beats the predeclared threshold (`r < -0.5, p < 0.05` or a similarly justified criterion).
- Prefer “binary review triage” and “authoring/need scheduling” over “score calibration.”
- Preserve negative results: failed gating, failed calibration, pro-priority mismatch, and dead closure/DescriptionGain branches strengthen the paper if reported honestly.
