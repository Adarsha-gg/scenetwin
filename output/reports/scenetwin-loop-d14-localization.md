# D14 — Can we localize WHICH claim is wrong (reference-free)?

Prior rounds detect AD errors at the **clip level** (fabrication AUC 0.835–0.945).
A deployable audit should point to the *specific* wrong/omitted claim. This tests
whether reference-free lexical signals can localize the injected error to the
correct sentence, using cached ground truth only.

- Script: `cursor/research/loop_d14_localization.py`
- Data: `cursor/output/halluc_gate/halluc_gate.csv` (expert / halluc / para AD text,
  60 clips), `cursor/output/relational_hallucination_probe_set/probes.csv`
  (76 swap probes `true->foil`).
- Rules: stdlib-only Python; no API/GPU/network. Numbers are regenerated by the
  script; nothing fabricated.

## Task 1 — Sentence alignment (ground-truth error location)

All **60/60** clips are cleanly alignable: expert and halluc have equal sentence
counts (0 positional mismatches), so the changed sentence(s) — the injected
error location — are recovered by a positional diff.

- Mean **3.55** sentences/clip; mean **2.30** changed sentences/clip.
- #changed-sentences distribution: 1→6, 2→32, 3→20, 4→2. Every clip has ≥1
  changed sentence (localization-usable n = 60).

## Task 2 — Reference-free localizer (text-only) — NEGATIVE

Without per-sentence visual grounding (not cached), suspicion can only be a
text-only heuristic. Top-1 = highest-suspicion sentence is a changed sentence.

| localizer | top-1 |
|---|---|
| random-sentence baseline | 0.667 |
| **structural: "pick first sentence"** | **0.917** |
| structural: "pick sentence #2" | 0.783 |
| structural: "pick last sentence" | 0.250 |
| content: sentence_length | 0.917 |
| content: max_idf (rarest word) | 0.917 |
| content: numeral_count | 0.917 |
| content: sum_idf (specificity) | 0.900 |
| content: mean_idf (rarity) | 0.650 |

**The content signals do not beat a trivial positional prior.** The best content
localizer (0.917) exactly ties "always pick the first sentence" (0.917) →
**content lift over structure = +0.000**. The reason is structural, not semantic:
the **opening scene-setting sentence is changed 55/60** times (it packs the
concrete objects/roles where swaps land), while the **closing mood/atmosphere
sentence is changed only 15/60** (boilerplate, rarely swapped). A content scorer
just picks the densest sentence, which coincides with the opening. It carries
**no error-specific information** — it cannot tell a *wrong* claim from a merely
*detailed* one. So reference-free claim-level localization is **not demonstrated**
here; the apparent 0.917 is a dataset-structure artifact.

## Task 3 — Reference-COMPARISON localizability (the working path)

Given a *trusted* reference AD, the injected span is pinpointable:

- Sentence-alignment diff recovers a changed sentence for **60/60 = 100%** of
  clips (exact, by construction).
- Probe swaps as spans (cached fuzzy mention labels): foil appears in halluc
  **69.7%**, true in expert **61.8%**, **clean swap 52.6%** (foil in H, true in
  E, true not in H). By type: count 69%, action_relation 54%, spatial 44%,
  who_role 40%.

Caveat found and reported: the probe `swap_text` foils are **QA distractors, not
the literal text edit**. E.g. the pottery clip lists `vase->clay jar`, but the
injected text edit is vase→"clay bowl". Exact foil-phrase substring in halluc is
therefore only **3.9%** (token-overlap 31.6%). **Use the Task-1 alignment diff,
not the probe foils, as the literal localization ground truth.** The probe labels
are still valid for the fuzzy semantic-swap rate above.

## Task 4 — Verdict

- **Reference-free zero-shot claim localization is NOT feasible with lexical
  signals alone.** Text-only top-1 (0.917) is fully explained by a positional
  prior; the genuine error-specific lift is ~0. Ceiling of the text-only route =
  the positional prior, which does not generalize to real ADs without a fixed
  scene→detail→mood template.
- **Reference-comparison localization works today**: given a trusted AD, sentence
  diff is exact (100%) and semantic swaps are lexically clean ~53% of the time.
  This is the deployable near-term path (audit a candidate AD against a trusted
  one).

### BLOCKED — needed for a genuine zero-reference localizer

Per-sentence **visual grounding** is required and is not cached:

- Split each candidate AD into claims; for each claim compute a **CLIP
  frame-match score** and/or a **frame-grounded yes/no ADQA**; flag the
  lowest-grounded claim as the suspected error.
- Requires: the 60-clip **frames** + a **CLIP encoder** + **ADQA generation** —
  all video/CLIP/API calls unavailable in this cached, stdlib-only environment.
- Expected payoff: this is the only route that can distinguish a *wrong* claim
  from a merely *detailed* one, which the text-only signal provably cannot.
